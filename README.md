# Cannon Hoops

A small Unity prototype where you drive around an arena, collect basketballs, aim a mounted cannon, and shoot through hoops to score.

[Play the WebGL build](https://cannon-hoops-build.pages.dev/)

> **Project status:** Cannon Hoops is an old learning project and is not under active development. It is kept online as a playable snapshot of my earlier Unity work, including its prototype visuals and rough edges.

## Gameplay

Explore the arena and collect basketballs to use as ammunition. Adjust the cannon's angle, line up a hoop, and fire. Every successful shot increases the score.

## Controls

- Move: `WASD` or arrow keys
- Aim the cannon: `Q` and `E`
- Fire: `Space`
- Reset position and rotation: `R`
- Straighten rotation: `F`

## Built With

- Unity 2021.3.45f2
- C#
- Universal Render Pipeline
- Unity WebGL

## Run in Unity

Clone the repository and open it through Unity Hub with Unity 2021.3.45f2. Open `Assets/Scenes/Main.unity`, then enter Play Mode.
